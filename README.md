# Fahrzeugverwaltung – Fuhrpark

Mobile PWA für die Verwaltung von **Autos und Motorrädern**.

## Funktionen
- Fahrzeugtyp: Auto oder Motorrad
- Suche
- Kilometerstand und Kilometerhistorie
- Service/Reparaturen und Kosten
- TÜV-Überwachung
- Erinnerungen
- Fotos per Kamera/Galerie
- Dokumente
- JSON-Sicherung und Import
- Offline-Nutzung über Service Worker
- Installation als App auf Android/Chrome

## GitHub Pages
Repository auf GitHub anlegen, alle Dateien hochladen und unter **Settings → Pages** die Veröffentlichung über den Branch `main` und Ordner `/ (root)` aktivieren.

Danach die erzeugte Pages-Adresse auf dem Xiaomi 15 mit Chrome öffnen und über **⋮ → App installieren** bzw. **Zum Startbildschirm hinzufügen** installieren.

Die Fahrzeugdaten bleiben weiterhin lokal im Browser/App-Speicher. Die GitHub-Seite speichert deine Fahrzeugdaten nicht auf GitHub.
